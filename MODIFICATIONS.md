# Modifications

This repository contains a modified version of GymMane. Development of the
Infyter variant began on 22 September 2026.

Material changes include:

- product name changed to Infyter;
- Android application identifier changed to `com.infyter.app`;
- default language changed to Spanish and Spanish catalogue coverage expanded;
- visual palette changed to black, graphite, silver and red;
- launcher icon and application branding replaced;
- profile defaults made neutral, without an automatic avatar or banner;
- profile medals and navigation icons adapted to the new palette;
- author-promotion and donation links removed from the user interface;
- legal, source-code and third-party-license disclosures added;
- backup/import entries removed from the visible Data settings section.

The Git history is the authoritative detailed record of subsequent changes.
Every released binary must correspond to a tagged or otherwise immutable
revision of this repository.
